# حفنة × NEXORA — تصور تجربة العميل

Mini Prototype تفاعلي مستقل لأغراض العرض، وليس نظامًا مستخدمًا لدى حفنة أو شراكة مع النشاط. جميع الأرقام ومخرجات الحملات افتراضية.

## التشغيل

يتطلب Node.js 22.6 أو أحدث وnpm.

```bash
npm install
npm run dev
```

افتح العنوان الذي يعرضه Vite. البناء ومعاينة نسخة الإنتاج:

```bash
npm run build
npm run preview
npm test
```

## العرض خلال 60–90 ثانية

1. ابدأ بـ«جرّب التجربة كعميل»، ثم «متابعة كتجربة».
2. اختر مكافأة وتابع إلى سبب العودة.
3. افتح رؤية النشاط: الأرقام كلها تجريبية مع تنبيه ثابت.
4. افتح محاكاة استرجاع العملاء، عدّل الرسالة وشغّل المحاكاة.
5. انتقل إلى الفكرة الأساسية، ثم «هل هذه الفرصة مهمة لكم؟».
6. اختر المسار المناسب: نظام مشابه أو معرفة المزيد.

الحاسبة وتفاصيل مؤشرات القياس متاحة لمن يريد استكشافًا أعمق. يمكن فتح تجربة العميل أو رؤية النشاط من أعلى الصفحة. «إعادة التجربة» يمسح الاختيارات والمحاكاة ويعيد البداية.


## Phase 2 — HAFNA DROP

إضافة مستقلة إلى المشروع نفسه. تجربة العودة ولوحة التحكم ومحاكاة الاسترجاع والحاسبة لم تُعد كتابتها.

المسار الجديد السريع:

1. من شاشة البداية اضغط «اكتشف اختيار حفنة لك» أو «اكتشف الـDROP» في بطاقة DROP #001.
2. افتح LOCKED، ثم اختر إجابات أربعة أسئلة قصيرة.
3. تظهر النتيجة بعد 1.2 ثانية. كل الأسماء والمُدد توضيحية.
4. احصل على Digital Pass، ثم حاكِ استخدامه.
5. افتح «شارك نتيجتك» لمعاينة رأسية قابلة للتصوير؛ لا مشاركة فعلية.
6. انتقل إلى رؤية النشاط: funnel ومقاييس بأرقام تجريبية.
7. «تابع رحلة العميل بعد الزيارة» يربط مباشرة بتجربة العودة الحالية. ويمكن فتح لوحة العودة مباشرة أو التبديل بين قسمي رؤية النشاط.

تبديل قسمي النشاط يحافظ على مدخلات الحاسبة وحالة الحملة أثناء وجودك في رؤية النشاط. Reset يمسح إجابات الذوق والـPass، بالإضافة إلى حالات التجربة القديمة. إعادة تحميل الصفحة تمسح كل حالة الجلسة.

الكود الجديد في `src/features/hafna-drop/`، وبياناته في `src/data/mockData.ts`. `BusinessView` يربط المكونات الحالية بالجديدة دون إعادة بناء Dashboard. تُحمّل تجربة DROP وقياسها عند الحاجة. لم تُضف dependencies.

أسماء النتائج Demo فقط:

- التجربة المختلفة مع مزاج الطاقة أو طعم قوي: MIDNIGHT 01.
- التجربة المختلفة مع اختيارات أكثر هدوءًا: HORIZON 01.
- الاختيار الكلاسيكي الساخن: SIGNATURE 01.
- الاختيار الكلاسيكي البارد: DAYLIGHT 01.

ملف الاختيارات يوضح جميع التفضيلات الأربعة في النتيجة. لا يوجد AI API أو جمع بيانات أو توصية لمنتج حقيقي. رمز HF-D001-0842 ثابت وغير صالح للاستخدام أو التحقق، والـ48 ساعة افتراضية دون حجز أو عد تنازلي فعلي.

مقاييس DROP توضح المقامات: إكمال الأسئلة 492/680، فتح النتيجة 492/2410، استخدام الـPass 163/492، العودة 31/163. معدل المشاهدة يحتاج إجمالي الظهور، والتحول إلى زيارة يتطلب تحققًا داخل الفرع. لا يُستنتج شراء من استخدام الرمز تلقائيًا. بيانات DROP وبيانات Retention فوجان افتراضيان مستقلان؛ الربط توضيحي ولا يجمعهما في نتائج حقيقية.

اقتراحات DROP #002 معاينة فقط، ولم تُنفذ أي لعبة إضافية. الفكرة اختبار صغير حول هدف تجاري، ثم قياس وتعلّم وتحسين، وليست منتجًا جاهزًا للبيع.

## الإعدادات

- `src/config/brand.ts`: اسم النشاط، نوعه، شعار اختياري، الألوان، خيارات المكافآت، المقاييس.
- `src/config/contact.ts`: استبدل `WHATSAPP_NUMBER` بالرقم الحقيقي بصيغة دولية من أرقام فقط، دون `+` أو مسافات. الزر معطل قبل ذلك. لا يُستخدم أي رقم من مصادر أخرى.
- `src/data/mockData.ts`: الأرقام التجريبية، مجموعات العملاء، المؤشرات والتدخلات.

الاتجاه البصري محايد؛ الاسم نص عادي وليس شعارًا رسميًا. تعديل النشاط يتطلب مراجعة النصوص الخاصة بحفنة في الصفحات وبيانات المشاركة أيضًا؛ الإعدادات تغطي مكونات الهوية الأساسية.

## النشر على Vercel

المشروع جاهز للنشر، ولم يُنشر تلقائيًا إلى حساب Vercel.

استورد مجلد المشروع أو المستودع في Vercel باختيار Vite، مع:

- Build command: `npm run build`
- Output directory: `dist`

ملف `vercel.json` جاهز. لا تحتاج إلى متغيرات سرية أو قاعدة بيانات أو Backend.

بعد معرفة رابط النشر، أضف `og:url`، واجعل `og:image` في `index.html` عنوانًا مطلقًا مثل `https://YOUR-DOMAIN/og-preview.png` لضمان عمل معاينة WhatsApp والمنصات الاجتماعية. أضف canonical عند اعتماد الرابط النهائي. صورة المشاركة موجودة في `public/og-preview.png`.

## الحسابات وحدود التفسير

- 118 ÷ 312 × 100 = 37.8%؛ في هذا المثال هو معدل العودة للشراء الثاني للمجموعة الجديدة. قياس Repeat Purchase Rate العام يتطلب تحديد الفترة والمجموعة منفصلًا.
- محاكاة الحملة: استهداف 23، عودة 7، معدل استرجاع 30.4%، و7 عمليات إضافية مفترضة. المحاكاة حتمية؛ تعديل النص لا يغير النتائج ولا يثبت سببية التدخل.
- الحاسبة: العملاء الجدد × الزيادة بالنقاط المئوية ÷ 100، مقربة لأسفل، ثم × متوسط الطلب. نفترض عملية إضافية واحدة لكل عميل إضافي يعود. الناتج مبيعات قبل التكاليف وليس ربحًا أو ROI صافٍ. النسبة المستهدفة الأقل لا تنتج زيادة.
- الأعداد 312 → 118 → 74 → 23 → 11 تعرض مراحل العلاقة؛ مجموعتا الانقطاع والاسترجاع ليستا قمع تحويل واحدًا للفوج الجديد.

## الخصوصية والأداء

لا تسجيل دخول، لا APIs، لا إرسال رسائل، لا جمع جوالات، لا cookies، لا localStorage، لا بيانات شخصية أو تتبع. حالة العرض في ذاكرة React وتختفي عند التحديث أو إعادة التجربة. رابط WhatsApp — بعد إعداد الرقم — يفتح خارجيًا بمبادرة المستخدم، ولا يرسل رسالة تلقائيًا.

React + TypeScript + Vite فقط مع خط عربي محلي. لوحة التحكم تُحمّل عند الحاجة. الحركات CSS خفيفة وتُوقف عند تفضيل تقليل الحركة. لا فيديوهات أو صور Stock أو مكتبة رسوم ثقيلة. Dialog أصلي مع حجز التركيز، Escape للإغلاق، وأزرار قابلة لاستخدام لوحة المفاتيح. الواجهة عربية RTL.
